# Проверка «проходит ли IP через белый список»

Задача: понять эмпирически, какие облака/адреса остаются доступны с мобильного
интернета в момент ограничений, и можно ли использовать такую машину как релей.

Тест имеет смысл **только когда белый список реально активен**. В обычное время
всё открывается, и результат ничего не значит.

## Что нужно

1. Ноутбук с интернетом **через раздачу с телефона** (не через Wi-Fi домашнего провайдера).
2. VPN на ноутбуке **выключен** — иначе тест бессмыслен.
3. Список IP-кандидатов.

## Кандидаты

Сначала бесплатные — те, что уже есть:

```text
# candidates.txt
monitor        217.28.222.170
old-vpn-1      77.110.99.29
old-vpn-2      45.150.32.145
```

Потом платные: арендуй почасово самый дешёвый VPS в российских облаках, чьи
подсети теоретически могут быть в списке:

| Облако | Почасовая | Замечание |
|---|---|---|
| Yandex Cloud | да | дороже остальных, но чаще всего упоминается |
| VK Cloud | да | |
| Selectel | да | |
| Cloud.ru | да | |
| Timeweb Cloud | да | |

Ориентир — 1–5 ₽/час за минимальную конфигурацию. Ставить туда ничего не нужно:
достаточно, чтобы машина пинговалась и слушала порт.

## Запуск

```bash
./scripts/whitelist-check.py \
  --operator MTS --region Москва \
  --out whitelist-results.md \
  candidates.txt
```

Скрипт проверяет:

- **контроль разрешённого** — `gosuslugi.ru:443`. Если не открывается, тест недействителен;
- **контроль запрещённого** — `1.1.1.1:443`. Если открывается, белого списка сейчас нет;
- каждого кандидата на портах **443, 80, 22**.

Результат дописывается в `whitelist-results.md` таблицей — удобно копить по
операторам, регионам и датам.

## Как читать

| Результат | Значение |
|---|---|
| `ПРОХОДИТ (443)`, контроль заблокирован | IP в белом списке — можно пробовать как релей |
| `не проходит` | диапазон не разрешён, дальше не тратить время |
| `частично (не 443)` | открыт только 80/22 — релей возможен, но протокол придётся подгонять |
| всё открыто | белого списка нет, повтори тест позже |

## Что делать с результатом

Если нашлось облако, чей IP проходит:

1. Проверь, что с этой машины есть выход за границу (в момент ограничений):
   ```bash
   curl -s -m 5 https://api.ipify.org
   curl -s -m 5 -o /dev/null -w "%{http_code}\n" https://<зарубежный-сервер>:443
   ```
2. Если выход есть — схема «телефон → RU-релей → зарубежный сервер» рабочая.
3. Учти: почти все российские облака запрещают VPN/прокси в договоре, а сервер
   находится под российской юрисдикцией. Это риск потери машины и данных.

## Ограничения метода

- Списки у операторов и регионов **разные** — тестируй на тех, где реально сидят пользователи.
- Список **меняется**, иногда в течение суток.
- Один удачный тест — не гарантия: повтори 2–3 раза в разные дни.
- Раздача с телефона может кэшировать DNS — проверяй именно TCP-соединения, как делает скрипт.

## Отдельно

Не путай это с обходом DPI. Здесь вопрос не «как замаскировать трафик», а
«есть ли вообще разрешённый адрес, до которого можно дотянуться». Если белый
список по IP — маскировка не помогает, помогает только наличие такого адреса.
